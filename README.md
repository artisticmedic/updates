# Update feeds

Each app checks one small file here to learn whether a newer version exists.

| App | Feed |
|---|---|
| [No Orange Dot](https://github.com/artisticmedic/no-orange-dot) | `no-orange-dot/latest.json` |

A feed names the newest version, where to download it, and the oldest macOS it runs on. The app installs
a download only when Apple has notarized it and it is signed by the same team as the app itself.
